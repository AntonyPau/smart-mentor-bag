- Book management

## Technologies Used
**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Node.js
- Express.js
- MongoDB

## How to Run This Project Locally

1. Clone the repository:
   `git clone https://github.com/YOUR-USERNAME/smart-mentor-bag.git`

2. Navigate to the backend folder:
   `cd smart-mentor-backend`

3. Install dependencies:
   `npm install`

4. Create a `.env` file in the backend folder and add your environment variables (e.g., database URL, email credentials).

5. Start the server:
   `npm start`
